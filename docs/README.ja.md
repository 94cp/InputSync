# 入力同期 · InputSync

macOSの画面共有で、接続先Macの入力ソースを手元のMacに合わせます。**インストールは手元のMacだけ**。接続先へのアプリ導入やSSH設定は不要です。

![InputSync の動作イメージ（仮想画面、実機録画ではありません）](assets/inputsync-demo.gif)

## 使い方

1. このプロジェクトの GitHub Releases から最新の `.dmg` をダウンロードして開き、**InputSync** を **Applications（アプリケーション）** にドラッグします。その後、アプリケーションフォルダから起動してください。Xcodeやビルドは不要です。
2. アプリの権限設定からアクセスを許可します。macOSによって項目名はアクセシビリティ、またはデバイス制御とデータアクセスに相当する名称です。
3. macOS標準の画面共有で接続先Macを開きます。
4. 本アプリでキーボード言語の同期を有効にします。手元の画面共有の「編集」メニューからも設定できます。
5. InputSyncの同期を有効にし、手元の入力ソースを切り替えます。約1秒待ってから接続先で入力してください。

ログイン時を含め、起動直後は一時停止状態です。同期時に接続先のメニューが一瞬表示されることがあります。

### 初回起動でブロックされた場合

このバージョンはApple Developer IDによる署名・公証を行っていないため、開発元や悪意のあるソフトウェアの有無を確認できないと表示される場合があります。

本プロジェクトのGitHub Releasesからダウンロードした場合は、次の手順で開けます。

1. アプリケーションフォルダからInputSyncを一度開きます。ブロックされたら、ゴミ箱に入れずに警告を閉じます。
2. **システム設定 → プライバシーとセキュリティ** を開き、**セキュリティ** までスクロールします。
3. InputSyncのメッセージにある **このまま開く** をクリックします。
4. 求められた場合はMacのログインパスワードまたはTouch IDで認証し、確認画面で **開く** をクリックします。

ボタンがない場合は、アプリをもう一度開いてから設定に戻ってください。起動後は画面上部のメニューバーに表示され、メインウインドウは開きません。その後、アプリの案内に従ってアクセシビリティを許可してください。起動の許可とは別の設定です。

## 仕組み

画面共有のキーボード言語同期では、接続先の入力ソース表示だけが変わり、使用中のアプリに反映されない場合があります。実験では、接続先のメニューを一度開いて閉じると切り替えが反映されました。InputSyncはこの操作を自動化します。

1. macOSの入力ソース変更通知を監視します。特定のキーやショートカットには依存しません。
2. 設定した時間（既定は0.5秒）待ち、画面共有による言語同期を先に進めます。
3. アクセシビリティで現在の共有画面の位置を取得し、接続先のメニューバー左上付近をクリックしてからEscapeで閉じます。

これは実験で確認した画面操作による回避策で、接続先の入力方式APIを直接呼ぶものではありません。メニューバーが想定位置でクリックできる必要があり、メニューが一瞬表示されます。

ウインドウの移動・サイズ変更に対応します。更新待機中に変更すると、その回はスキップされます。調整後に入力ソースを再度切り替えてください。全画面と拡大縮小の全組み合わせは未検証です。

## 表示と言語

「その他」からメニューバーの表示を選べます。初期設定の「自動」は判別できるキーボード配列を優先し、不明な場合はシステムの地域を使います。

- 中国本土・台湾・香港・マカオ：**中/英**
- 日本：**英数 / かな**
- 韓国：**한/영**
- その他：地球アイコン

表示の提案であり、キーの印字を読み取る機能ではありません。手動設定が優先され、キー割り当てや入力ソースは変更しません。

アプリの言語はmacOSの「言語と地域」で設定できます。8言語に対応し、その他は英語になります。

## 困ったとき

- **許可済みなのに使えない：**このアプリの権限をオフにして再度オンにし、アプリを再起動してください。更新後に再許可が必要な場合があります。
- **同期しない：**両アプリの同期設定を確認し、画面共有ウインドウをアクティブにしてください。待機時間を増やす方法もあります。
- **ログ：**「その他」から開けます。

macOS 27.2のABCと標準の簡体字ピンインで検証済みです。ほかの入力方式や旧バージョンは十分に検証していません。標準の画面共有向けで、Macの機種や固定のウインドウサイズに制限はありません。

## アンインストール

ログイン時の起動を無効にし、アプリを終了して削除します。必要ならログも削除できます：`~/Library/Logs/InputSync/events.log`。
