# 輸入法同步 · InputSync

一款 Mac 選單列工具，讓「螢幕共享」中的遠端輸入法跟隨本機。**僅需本機安裝**，遠端無需設定。

![InputSync 效果示範：虛擬介面，非實機錄影](assets/inputsync-demo.gif)

## 開始使用

1. 在本專案的 [GitHub Releases](https://github.com/94cp/InputSync/releases/latest) 下載最新版 `.dmg`，開啟後將 **InputSync** 拖入 **Applications（應用程式）**，再從「應用程式」開啟。不需安裝 Xcode 或自行編譯。
2. 透過應用程式的權限設定入口授權。依 macOS 版本，項目可能稱為「輔助使用」或裝置控制與資料存取。
3. 使用 macOS 內建「螢幕共享」連線至遠端 Mac。
4. 在本工具開啟鍵盤語言同步；也可在本機螢幕共享的「編輯」選單中開啟。
5. 開啟同步。照常切換本機輸入法，等約 1 秒再於遠端輸入。

每次啟動預設暫停，登入啟動亦同。同步時遠端選單可能短暫出現。

### 首次開啟：無法驗證應用程式

目前版本未使用 Apple Developer ID 簽章及公證，macOS 可能提示無法驗證開發者，或無法檢查是否包含惡意軟體。

若你是從本專案的 [GitHub Releases](https://github.com/94cp/InputSync/releases/latest) 下載，請依序操作：

1. 從「應用程式」開啟一次 InputSync。遭阻擋時關閉提示，不要移至垃圾桶。
2. 開啟 **系統設定 → 隱私權與安全性**，向下找到 **安全性**。
3. 找到 InputSync 的阻擋訊息，點擊 **強制打開**（按鈕名稱可能依版本不同）。
4. 依提示輸入 Mac 登入密碼或使用 Touch ID，再於確認視窗點擊 **打開**。

若找不到按鈕，請再次開啟應用程式，再回到設定查看。成功後工具會出現在螢幕頂端選單列，不會彈出主視窗。接著依應用程式提示授予輔助使用權限；允許開啟與輔助使用授權是兩個步驟。

## 更新

在選單中選擇「檢查更新…」，也可在「更多」開關自動檢查。確認更新後即可下載、安裝並重新啟動。0.7.0 需先手動升級一次。

## 運作原理

螢幕共享的鍵盤語言同步有時只更新遠端輸入法指示，目前應用程式仍使用舊的輸入狀態。實驗中，短暫開啟再關閉遠端選單後，切換才實際生效。InputSync 將此操作自動化。

1. 監聽 macOS 的本機輸入來源變更通知，不依賴特定按鍵或快速鍵。
2. 等待設定的延遲（預設 0.5 秒），讓螢幕共享先同步鍵盤語言。
3. 透過輔助使用取得目前視窗中的共享畫面位置，點擊遠端選單列左上方，再傳送 Escape 關閉選單。

這是經實驗驗證的介面刷新方法，並非直接呼叫遠端輸入法介面。它依賴遠端選單列位於可點擊的預期位置，因此同步時可能看到選單短暫出現。

可調整視窗大小與位置。若在等待更新時調整，本次會跳過；調整後再切換輸入法即可。全螢幕及各種縮放組合尚未全部驗證。

## 狀態列與語言

在「更多」中選擇狀態列標識。預設「自動」優先採用可辨識的鍵盤配置，否則依系統地區推薦：

- 中國大陸、台灣、香港、澳門：**中/英**
- 日本：**英数 / かな**
- 韓國：**한/영**
- 其他地區：地球圖示

這是顯示建議，不代表準確辨識鍵帽。手動選擇優先，不會修改快速鍵或輸入法。

介面依 macOS「語言與地區」中的應用程式語言設定顯示，提供八種語言；其他語言使用英文。

## 常見問題

- **已授權卻無法使用：**關閉再開啟本應用程式的權限，然後重新啟動。更新後可能需重新授權。
- **未同步：**確認兩個應用程式皆已開啟同步，保持遠端視窗作用中，或增加選單中的延遲。
- **日誌：**從「更多」開啟。

已在 macOS 27.2 驗證 ABC 與系統簡體拼音。其他輸入法及較舊系統尚未完整測試。適用於內建螢幕共享，不限定 Mac 機型或固定視窗大小。

## 移除

關閉登入啟動，結束並刪除應用程式。可另行刪除日誌：`~/Library/Logs/InputSync/events.log`。
