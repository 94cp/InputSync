# 입력 동기화 · InputSync

macOS 화면 공유에서 원격 Mac의 입력 소스를 로컬 Mac과 맞춥니다. **로컬 Mac에만 설치**하세요. 원격 앱이나 SSH 설정은 필요 없습니다.

![InputSync 동작 예시 — 가상 화면이며 실제 녹화가 아닙니다](assets/inputsync-demo.gif)

## 시작하기

1. 이 프로젝트의 [GitHub Releases](https://github.com/94cp/InputSync/releases/latest)에서 최신 `.dmg`를 다운로드해 여세요. **InputSync**를 **Applications(응용 프로그램)**로 드래그한 뒤 응용 프로그램 폴더에서 실행하세요. Xcode 설치나 직접 빌드는 필요 없습니다.
2. 앱의 권한 설정에서 접근을 허용하세요. macOS 버전에 따라 손쉬운 사용 또는 기기 제어 및 데이터 접근에 해당하는 항목입니다.
3. macOS 기본 화면 공유로 원격 Mac에 연결하세요.
4. InputSync에서 키보드 언어 동기화를 켜세요. 로컬 화면 공유의 편집 메뉴에서도 설정할 수 있습니다.
5. InputSync의 동기화를 켜고 평소처럼 로컬 입력 소스를 바꾸세요. 약 1초 후 원격 Mac에 입력하세요.

로그인 시 실행을 포함해 앱은 항상 일시 정지 상태로 시작합니다. 동기화 중 원격 메뉴가 잠깐 나타날 수 있습니다.

### 처음 실행할 때 차단되는 경우

현재 버전은 Apple Developer ID 서명 및 공증을 받지 않아 개발자나 악성 소프트웨어 여부를 확인할 수 없다는 메시지가 표시될 수 있습니다.

이 프로젝트의 [GitHub Releases](https://github.com/94cp/InputSync/releases/latest)에서 다운로드했다면 다음 순서로 여세요.

1. 응용 프로그램 폴더에서 InputSync를 한 번 실행하세요. 차단되면 휴지통으로 이동하지 말고 알림을 닫으세요.
2. **시스템 설정 → 개인정보 보호 및 보안**에서 **보안** 항목까지 내려가세요.
3. InputSync 차단 메시지 옆의 **확인 없이 열기**를 클릭하세요.
4. 요청 시 Mac 로그인 암호나 Touch ID로 인증하고 확인 창에서 **열기**를 클릭하세요.

버튼이 없다면 앱을 다시 실행한 후 설정으로 돌아오세요. 실행되면 화면 위쪽 메뉴 막대에 표시되며 별도의 기본 창은 열리지 않습니다. 이어서 앱 안내에 따라 손쉬운 사용 권한을 허용하세요. 앱 실행 허용과 손쉬운 사용 권한은 별도입니다.

## 작동 원리

화면 공유의 키보드 언어 동기화가 원격 입력 소스 표시만 바꾸고 사용 중인 앱에는 반영되지 않을 때가 있습니다. 실험에서는 원격 메뉴를 잠깐 열었다 닫으면 변경이 적용되었습니다. InputSync는 이 동작을 자동화합니다.

1. macOS의 로컬 입력 소스 변경 알림을 감지합니다. 특정 키나 단축키에 의존하지 않습니다.
2. 설정한 시간(기본 0.5초) 동안 기다려 화면 공유가 먼저 언어를 동기화하도록 합니다.
3. 손쉬운 사용 API로 현재 공유 화면의 위치를 구하고 원격 메뉴 막대 왼쪽 위를 클릭한 뒤 Escape로 닫습니다.

이 방식은 실험으로 확인한 화면 조작 우회책이며 원격 입력기 API를 직접 호출하지 않습니다. 원격 메뉴 막대가 예상 위치에서 클릭 가능해야 하며 메뉴가 잠깐 보일 수 있습니다.

창 이동과 크기 조절을 지원합니다. 갱신 대기 중 변경하면 해당 동작은 건너뜁니다. 조절 후 입력 소스를 다시 전환하세요. 모든 전체 화면 및 배율 조합을 검증한 것은 아닙니다.

## 표시와 언어

더 보기에서 메뉴 막대 표시를 선택하세요. 기본값인 자동은 확인 가능한 키보드 배열을 우선하며, 그렇지 않으면 시스템 지역을 사용합니다.

- 중국 본토·대만·홍콩·마카오: **中/英**
- 일본: **英数 / かな**
- 대한민국: **한/영**
- 기타 지역: 지구본

표시 추천일 뿐 키캡 글자를 정확히 읽는 기능은 아닙니다. 수동 선택이 우선하며 키 설정이나 입력 소스를 바꾸지 않습니다.

앱 언어는 macOS 언어 및 지역 설정을 따릅니다. 8개 언어를 지원하며 나머지는 영어로 표시됩니다.

## 문제 해결

- **허용했지만 사용할 수 없음:** 이 앱의 권한을 껐다 켠 후 앱을 다시 실행하세요. 업데이트 후 재허용이 필요할 수 있습니다.
- **동기화되지 않음:** 두 앱의 동기화 옵션을 확인하고 원격 창을 활성 상태로 유지하세요. 메뉴에서 지연 시간을 늘려볼 수도 있습니다.
- **로그:** 더 보기에서 여세요.

macOS 27.2의 ABC와 기본 간체 병음으로 검증했습니다. 다른 입력기와 이전 macOS는 충분히 테스트하지 않았습니다. 기본 화면 공유를 대상으로 하며 특정 Mac 모델이나 고정 창 크기를 요구하지 않습니다.

## 제거

로그인 시 실행을 끄고 앱을 종료한 뒤 삭제하세요. 필요하면 로그도 삭제할 수 있습니다: `~/Library/Logs/InputSync/events.log`.
